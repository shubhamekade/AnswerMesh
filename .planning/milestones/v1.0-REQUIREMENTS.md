## 1. Functional Requirements (MVP)

### 1.1 Foundation & Core Architecture
- [x] **REQ-F01 (Bootstrap & Lifecycle):** Plugin must register activation, deactivation, and uninstall hooks cleanly. Activation must provision custom database tables; deactivation preserves data; uninstall provides optional clean removal. (Outcome: Validated)
- [x] **REQ-F02 (Database Schema):** Provide versioned database migrations creating 5 custom tables (`wp_aiseo_scores`, `wp_aiseo_entities`, `wp_aiseo_questions`, `wp_aiseo_recommendations`, `wp_aiseo_visibility`). (Outcome: Validated)
- [x] **REQ-F03 (Settings Management):** Settings API for General options, AI provider configuration, SEO defaults, Schema options, Brand Voice guidelines, and Privacy/telemetry preferences. (Outcome: Validated)
- [x] **REQ-F04 (REST API Controller):** Secure REST API under namespace `/wp-json/aiseo/v1/` with permission callbacks (`manage_options` for admin, `edit_posts` for editorial features). (Outcome: Validated)
- [x] **REQ-F05 (Setup Wizard):** First-run onboarding wizard collecting core business identity and connecting initial AI provider. (Outcome: Validated)

### 1.2 Technical SEO & Structured Data Engine
- [x] **REQ-F06 (Metadata Management):** Output optimized SEO titles, meta descriptions, canonical URLs, robots directives, and OpenGraph tags on public frontend requests. (Outcome: Validated)
- [x] **REQ-F07 (Schema.org JSON-LD Generator):** Automatically generate valid Schema.org JSON-LD scripts (`WebSite`, `Organization`, `LocalBusiness`, `Person`, `Article`, `BlogPosting`, `Service`, `BreadcrumbList`, `FAQPage`). (Outcome: Validated)
- [x] **REQ-F08 (Schema Conflict Detection):** Detect schema duplication, multiple conflicting Organization entities, invalid syntax, or missing mandatory properties. (Outcome: Validated)
- [x] **REQ-F09 (XML Sitemap & Breadcrumbs):** Generate clean XML sitemaps and breadcrumb trails with Schema integration. (Outcome: Validated)
- [x] **REQ-F10 (SEO Plugin Compatibility Layer):** Detect active third-party SEO plugins (Yoast, Rank Math, All in One SEO) and provide compatibility mode suppressing duplicate tags. (Outcome: Validated)

### 1.3 Content & Entity Analyzer
- [x] **REQ-F11 (DOM & Content Parsing):** Parse post content to extract headings hierarchy (H1–H6), word counts, readability, image alt attributes, and link ratios. (Outcome: Validated)
- [x] **REQ-F12 (Question Discovery & Coverage):** Identify user questions, categorize by intent, and assess answer clarity (Answered, Weak, Missing). (Outcome: Validated)
- [x] **REQ-F13 (Entity Extraction & Knowledge Base):** Map content mentions against verified business knowledge (founder, team, services, locations, USPs), tracking consistency. (Outcome: Validated)
- [x] **REQ-F14 (Trust & Citation Readiness Check):** Detect author bios, verifiable credentials, publication/update timestamps, citations, and external evidence links. (Outcome: Validated)
- [x] **REQ-F15 (Bounded Site Crawler):** Execute background crawls using WP Cron or chunked REST batches with strict boundaries (50/500/5000 limits). (Outcome: Validated)

### 1.4 Diagnostic Scoring & Evidence Engine
- [x] **REQ-F16 (AnswerMesh Visibility Score):** Calculate 0–100 diagnostic score weighted as: Technical SEO (20%), AEO (20%), GEO (20%), Entity Clarity (15%), Trust Signals (15%), Content Quality (10%). (Outcome: Validated)
- [x] **REQ-F17 (Evidence Model Recommendations):** Every diagnostic issue generates a structured recommendation with Observation, Evidence, Impact, Recommendation, Priority, Confidence, and Acceptance Check. (Outcome: Validated)

### 1.5 AI Intelligence & Safe Content Assistant
- [x] **REQ-F18 (Provider Abstraction Interface):** Core `AIProviderInterface` decoupling business logic from external LLMs. (Outcome: Validated)
- [x] **REQ-F19 (Initial Adapters):** Implement native adapters for OpenAI and Google Gemini with server-side AES-256-CBC API key encryption. (Outcome: Validated)
- [x] **REQ-F20 (Context-Rich Prompt Construction):** Build prompts incorporating verified Business Knowledge, page context, target audience, brand voice, and strict anti-hallucination instructions. (Outcome: Validated)
- [x] **REQ-F21 (Human-in-the-Loop Preview & Apply):** All AI-generated content presents an interactive visual diff preview modal before user confirmation. (Outcome: Validated)
- [x] **REQ-F22 (Offline / No-AI Fallback):** Full technical SEO, rule-based AEO/GEO analysis, and Schema generation operate without an active AI API key. (Outcome: Validated)

### 1.6 Admin Interface & Editor Integration
- [x] **REQ-F23 (React Admin Dashboard):** Native React dashboard rendered in `admin.php?page=answermesh` using `@wordpress/components`. (Outcome: Validated)
- [x] **REQ-F24 (Gutenberg Block Editor Sidebar):** Registered sidebar plugin showing live page scores, detected questions, schema preview, and AI action buttons. (Outcome: Validated)

## 2. Non-Functional Requirements (NFR)

- [x] **NFR-01 (Security & Sanitization):** Sanitization, prepared statements, capability checks, encrypted credentials. (Outcome: Validated)
- [x] **NFR-02 (Performance):** Public front-end execution overhead strictly under 50ms (achieved 0.0125ms); zero external HTTP/AI calls during frontend requests. (Outcome: Validated)
- [x] **NFR-03 (Compatibility):** WordPress 6.0+ and PHP 8.1+ compatibility. (Outcome: Validated)
- [x] **NFR-04 (Privacy & Telemetry):** Explicit opt-in toggles, clear retention disclosure, full uninstall data purge. (Outcome: Validated)
- [x] **NFR-05 (Code Quality & Testing):** WPCS standards compliance, automated test suite with 115 passing assertions. (Outcome: Validated)
