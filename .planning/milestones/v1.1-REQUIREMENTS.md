## 1. Functional Requirements (Milestone 2)

### 1.1 Topic Clusters & Semantic Depth (Phase 8)
- [x] **REQ-M2-01 (Cluster Data Architecture & Schema):** Provision database structures for topic clusters (table `wp_aiseo_clusters` or metadata schema) storing cluster title, slug, primary pillar post ID, assigned supporting cluster post IDs, core entities, and topical coverage score.
- [x] **REQ-M2-02 (Automated Cluster Mapping):** Heuristic and entity-based clustering engine that groups existing posts into semantic topic clusters based on shared entities, common taxonomy, heading semantics, and content similarity.
- [x] **REQ-M2-03 (Topic Gap & Subtopic Discovery):** Identify semantic subtopic gaps within a cluster (questions and subtopics answered in some cluster posts but missing across the group) and flag orphan posts lacking a cluster association.
- [x] **REQ-M2-04 (Cluster Health & Admin Visualization):** Admin UI in the React dashboard rendering visual topic cluster cards, pillar-to-support hierarchy, topical completeness percentages, and cluster-level diagnostic recommendations.

### 1.2 Content Decay & Sitewide Internal Link Graph (Phase 9)
- [x] **REQ-M2-05 (Content Freshness & Decay Evaluator):** Algorithmic decay scoring calculating freshness based on publication date, modified date, entity revisions, and visibility trends, classifying content into `Fresh`, `Aging`, `Decaying`, or `Critical`.
- [x] **REQ-M2-06 (Internal Link Graph Engine):** Sitewide link parser and graph generator that analyzes all internal hyperlinks (`href`), tracking source post, target post, anchor text, rel attributes, and target post type.
- [x] **REQ-M2-07 (Link Equity & Orphan Page Metrics):** Calculate in-degree (inbound link count), out-degree (outbound link count), anchor text diversity, and detect link-isolated / true orphan pages (0 inbound internal links).
- [x] **REQ-M2-08 (Smart Anchor Text Opportunity Engine):** Contextual scanner identifying relevant phrases, keywords, and entity mentions inside post paragraphs that could naturally link to related cluster posts or pillar pages without keyword stuffing.
- [x] **REQ-M2-09 (Human-in-the-Loop Gutenberg Link Insertion):** Gutenberg sidebar panel displaying contextual link suggestions with 1-click insertion or copy, adhering to strict human approval before altering post HTML.
- [x] **REQ-M2-10 (Content Decay & Link Hub Dashboard):** Dedicated Admin tab in the React dashboard displaying decaying content queues, orphan page resolution list, anchor text distribution chart, and manual link recalculation trigger.

## 2. Non-Functional Requirements (Milestone 2)

- [x] **NFR-M2-01 (Performance & Background Execution):** Sitewide link graph generation and cluster recalculation must execute asynchronously via WP-Cron or chunked REST batches, never blocking admin page loads or public requests.
- [x] **NFR-M2-02 (Safe Content Modification):** Link insertions must never automatically rewrite post content without explicit human confirmation in the Gutenberg editor.
- [x] **NFR-M2-03 (Zero Frontend Overhead):** Milestone 2 features must introduce zero additional frontend overhead during visitor page requests (<50ms target maintained).
- [x] **NFR-M2-04 (Automated Test Coverage):** Unit and integration test suites for cluster grouping algorithms, decay score formulas, and internal link graph calculations.
