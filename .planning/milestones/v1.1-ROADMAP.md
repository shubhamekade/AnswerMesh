## Milestone 2: Topic Clusters, Content Decay & Internal Links (Phases 8–9)

### Phase 8: Topic Clusters & Semantic Depth Engine
- **Goal:** Group website content into semantic pillar-and-cluster taxonomies, detect topic coverage gaps, and measure topical authority.
- **Deliverables:**
  - Database schema & migration for `wp_aiseo_clusters` storing cluster metadata, pillar assignment, and member posts.
  - Automated heuristic and entity-driven clustering engine identifying core pillars and supporting cluster posts.
  - Subtopic gap and orphan post identification.
  - React Admin Cluster Explorer tab with interactive visual cluster cards and cluster health scores.
- **Plans Executed:**
  - `08-01`: Cluster Data Architecture, Custom Table Migration & REST Endpoints (REQ-M2-01) — Completed.
  - `08-02`: Semantic Cluster Discovery, Gap Analyzer & Orphan Classifier (REQ-M2-02, REQ-M2-03) — Completed.
  - `08-03`: React Cluster Explorer & Admin Management UI (REQ-M2-04) — Completed.

---

### Phase 9: Content Freshness & Sitewide Internal Link Graph
- **Goal:** Monitor content decay over time and construct an interactive internal link graph with human-in-the-loop anchor recommendations.
- **Deliverables:**
  - Algorithmic content freshness & decay scoring engine with status tiers (`Fresh`, `Aging`, `Decaying`, `Critical`).
  - Sitewide internal hyperlink parser and in-memory link graph tracking in-degree, out-degree, and orphan pages.
  - Contextual anchor text opportunity engine matching post content against relevant cluster articles.
  - Human-in-the-loop Gutenberg block editor sidebar widget for 1-click internal link insertion.
  - React Admin Link & Decay Hub tab showing orphan pages, decaying content queues, and anchor text distribution.
- **Plans Executed:**
  - `09-01`: Content Freshness & Decay Evaluator (REQ-M2-05) — Completed.
  - `09-02`: Sitewide Link Graph Engine & Smart Anchor Discovery (REQ-M2-06, REQ-M2-07, REQ-M2-08) — Completed.
  - `09-03`: Gutenberg 1-Click Link Assistant & Admin Decay/Link Hub (REQ-M2-09, REQ-M2-10) — Completed.
