## 1. Functional Requirements (Milestone 3)

### 1.1 Observed AI Search Visibility Engine (Phase 10)
- [x] **REQ-M3-01 (Visibility Data Model & CRUD):** Data access and lifecycle manager for `wp_aiseo_visibility` storing `id`, `query`, `platform` (`chatgpt`, `gemini`, `perplexity`, `copilot`), `observed`, `mention`, `position_context`, `source_url`, `competitors_json`, and `captured_at`.
- [x] **REQ-M3-02 (Scheduled Sampling & Query Runner):** WP-Cron background runner (`AnswerMesh\VisibilityRunner`) and REST manual sampling endpoint that queries target AI search engines with prioritized business questions/topics to detect brand citations.
- [x] **REQ-M3-03 (Citation & Brand Mention Parser):** Engine analyzing AI response text to detect exact URL citations, naked domain references, branded mentions, and surrounding contextual snippets.
- [x] **REQ-M3-04 (Competitor Observation & Share of Voice):** Parser extracting rival domains and brand entities mentioned in the same generative search answers, computing comparative share of voice across platforms.
- [x] **REQ-M3-05 (Visibility Index & Trend Analytics):** Composite AI Visibility Index (0–100) aggregating platform presence, citation rate, and mention position over 7-day, 30-day, and 90-day rolling windows.
- [x] **REQ-M3-06 (React Admin Visibility Dashboard & Export Hub):** Full React Admin tab (`VisibilityView.js`) with platform comparison cards, timeline trend charts, query inspection table, and CSV export.

---

## 2. Non-Functional Requirements (Milestone 3)

- [x] **NFR-M3-01 (Rate Limiting & Cost Protection):** Visibility queries must respect configured daily/monthly query quotas, preventing runaway API spend.
- [x] **NFR-M3-02 (Offline Simulation Fallback):** Safe fallback and deterministic simulation when external search engine APIs or API keys are not configured.
- [x] **NFR-M3-03 (Data Retention & Automatic Pruning):** Automatic maintenance routine pruning observation records older than 90 days to prevent unbounded table growth.
- [x] **NFR-M3-04 (Automated Unit Testing):** Complete test suite validating parsing of citations, competitor extraction, visibility index calculation, and REST endpoints.
