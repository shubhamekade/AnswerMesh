## Milestone 3: Observed AI Search Visibility Monitoring (Phase 10)

### Phase 10: Observed AI Search Visibility Engine
- **Goal:** Track, sample, and record empirical visibility of the site across major generative search platforms (ChatGPT Search, Google Gemini, Perplexity AI, Microsoft Copilot).
- **Deliverables:**
  - Database CRUD and storage manager for `wp_aiseo_visibility`.
  - Scheduled query sampling runner via WP-Cron (`aiseo_daily_visibility_check`) and manual REST sampler.
  - Generative search response parser extracting site URL citations, naked domain mentions, brand names, and competitor domains.
  - AI Visibility Index (0–100) and competitor share of voice computation.
  - React Admin Visibility Dashboard with platform breakdown, live query tester, observation logs, and 1-click CSV export.
- **Plans Executed:**
  - `10-01`: Visibility Data Model, Storage Manager & REST Endpoints (REQ-M3-01, NFR-M3-03) — Completed.
  - `10-02`: Scheduled Sampling Runner, Citation Parser & Competitor Tracker (REQ-M3-02, REQ-M3-03, REQ-M3-04, REQ-M3-05, NFR-M3-01, NFR-M3-02) — Completed.
  - `10-03`: React Admin Visibility Dashboard & Export Hub (REQ-M3-06) — Completed.
