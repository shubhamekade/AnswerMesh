# Plan 02-01: Metadata & Frontend Tag Injection

**Phase:** 2 — Technical SEO Engine & Structured Data  
**Plan ID:** 02-01  
**Type:** Tracer Slice  
**Requirements Addressed:** REQ-F06, NFR-01, NFR-02, NFR-03  
**Status:** Planned  

---

## 1. Objective
Build frontend metadata engine injecting optimized SEO title tags, meta descriptions, canonical URLs, robots directives, and OpenGraph/Twitter card markup with zero frontend latency overhead (<50ms).

---

## 2. Context & Design Decisions
- **Hook Placement:** `wp_head` filter priority 1 for canonical and robots, `pre_get_document_title` for titles.
- **Post Meta Storage:**
  - `_aiseo_title`
  - `_aiseo_description`
  - `_aiseo_canonical`
  - `_aiseo_robots_noindex`
  - `_aiseo_robots_nofollow`
  - `_aiseo_og_image`
- **Fallback Rules:** Post title, auto-excerpt / first 160 characters, permalink, featured image.
- **Suppression:** Hook into `Compatibility::is_meta_handled_by_third_party()` to prevent duplicate tags when Yoast/RankMath active.

---

## 3. Detailed Tasks

### Task 1: Post Meta Helper & Sanitizer
- Create `includes/class-meta.php`:
  - Register post meta fields with `show_in_rest: true` and sanitization callbacks.
  - Getter methods with smart fallback logic:
    - `get_title(int $post_id): string`
    - `get_description(int $post_id): string`
    - `get_canonical_url(int $post_id): string`
    - `get_robots(int $post_id): array`
    - `get_og_data(int $post_id): array`

### Task 2: Public Frontend Output Renderer
- Create `public/class-meta-output.php`:
  - Hook to `pre_get_document_title`.
  - Hook to `wp_head` to render:
    - `<meta name="description" content="...">`
    - `<link rel="canonical" href="...">`
    - `<meta name="robots" content="...">`
    - `<meta property="og:title" ...>`, `<meta property="og:description" ...>`, `<meta property="og:url" ...>`, `<meta property="og:type" ...>`, `<meta property="og:image" ...>`
    - `<meta name="twitter:card" content="summary_large_image">`
  - Honor `answermesh_settings` toggles (`enable_og`, `canonical_enabled`).
  - Condition check: Bail if third-party SEO plugin handles metadata.

---

## 4. Verification & Acceptance Criteria
- [ ] Document title correctly overrides WordPress default on single posts and pages.
- [ ] Description, canonical, robots, and OpenGraph tags render valid HTML in `<head>`.
- [ ] Special characters properly escaped with `esc_attr()` / `esc_url()`.
- [ ] `php -l` passes on both files.
