# Plan 02-02: Schema.org JSON-LD Engine & Conflict Detector

**Phase:** 2 — Technical SEO Engine & Structured Data  
**Plan ID:** 02-02  
**Type:** Core Feature Subsystem  
**Requirements Addressed:** REQ-F07, REQ-F08, NFR-01, NFR-02  
**Status:** Planned  

---

## 1. Objective
Generate valid Schema.org JSON-LD graphs in `<head>` from verified business and post data, cache generated schemas, and implement conflict detection for duplicate entities and malformed JSON-LD.

---

## 2. Context & Design Decisions
- **Supported Types:**
  - Site/Global: `WebSite` (with SearchAction), `Organization` / `LocalBusiness`, `Person`.
  - Contextual: `Article`, `BlogPosting`, `WebPage`, `Service`, `BreadcrumbList`, `FAQPage`.
- **Single Graph Architecture:** Output one unified `<script type="application/ld+json">` containing `@context: "https://schema.org"` and `@graph: [...]` linking entities with `@id` URIs.
- **Caching:** Cache generated JSON-LD per post using transients or post meta cache. Invalidate on post save.
- **Conflict Detector:** Identify duplicate organizations, missing required attributes (`name`, `url`, `logo`), invalid date formats, and overlapping third-party schemas.

---

## 3. Detailed Tasks

### Task 1: Schema Generator Engine
- Create `includes/class-schema.php`:
  - Methods:
    - `build_website_schema(): array`
    - `build_organization_schema(): array`
    - `build_breadcrumbs_schema(int $post_id): array`
    - `build_post_schema(int $post_id): array`
    - `build_graph_for_request(): array`
  - ID URI referencing: `#website`, `#organization`, `#breadcrumb`, `#article`.

### Task 2: Schema Output Renderer with Caching
- Create `public/class-schema-output.php`:
  - Hook to `wp_head` priority 2.
  - Check transient cache `answermesh_schema_{post_id}`.
  - Render sanitized `<script type="application/ld+json">` with `wp_json_encode($graph, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE)`.
  - Invalidate cache on `save_post`.

### Task 3: Schema Conflict Detector
- Create `includes/class-schema-conflict.php`:
  - `detect_conflicts(string $html): array`
  - Regex scan for external `<script type="application/ld+json">`.
  - Parse and flag duplicate `@type: Organization`, conflicting entity names, or missing mandatory properties.

---

## 4. Verification & Acceptance Criteria
- [ ] Rendered JSON-LD parses as valid JSON with valid Schema.org vocabulary.
- [ ] Entities connected via `@id` references in `@graph`.
- [ ] Post cache invalidated on save.
- [ ] Conflict detector flags duplicate entities.
- [ ] `php -l` passes on all files.
