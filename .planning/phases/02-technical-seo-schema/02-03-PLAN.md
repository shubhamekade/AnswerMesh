# Plan 02-03: XML Sitemaps & Third-Party Compatibility Layer

**Phase:** 2 — Technical SEO Engine & Structured Data  
**Plan ID:** 02-03  
**Type:** Integration & Infrastructure  
**Requirements Addressed:** REQ-F09, REQ-F10, NFR-02, NFR-03  
**Status:** Planned  

---

## 1. Objective
Provide standards-compliant XML sitemaps integrated with WordPress core sitemaps or standalone rewrite, and implement the third-party compatibility detection layer (Yoast SEO, Rank Math, All in One SEO) to prevent duplicate metadata or schema collisions.

---

## 2. Context & Design Decisions
- **Sitemap Architecture:** Extend WordPress `WP_Sitemaps_Provider` or provide clean `/sitemap_answermesh.xml` fallback, respecting `noindex` post flags.
- **Compatibility Modes:**
  - `auto`: If Yoast / Rank Math / AIOSEO detected, automatically yield metadata to third-party plugin, but retain AnswerMesh Schema + AEO/GEO analysis.
  - `override`: AnswerMesh handles metadata, suppressing third-party output if possible.
  - `passthrough`: AnswerMesh skips metadata completely.
- **Third-Party Detection:** Detect active constants/classes:
  - Yoast: `WPSEO_VERSION` / `defined('WPSEO_FILE')`
  - Rank Math: `defined('RANK_MATH_VERSION')`
  - AIOSEO: `defined('AIOSEO_VERSION')`

---

## 3. Detailed Tasks

### Task 1: Third-Party Plugin Compatibility Layer
- Create `includes/class-compatibility.php`:
  - Methods:
    - `get_active_seo_plugins(): array`
    - `has_third_party_seo(): bool`
    - `is_meta_handled_by_third_party(): bool`
    - `is_schema_handled_by_third_party(): bool`
  - Integration with `Settings::get('seo', 'compatibility_mode')`.

### Task 2: XML Sitemap Provider
- Create `includes/class-sitemap.php`:
  - Integrate with core `wp_sitemaps_init` hook.
  - Exclude posts flagged with `_aiseo_robots_noindex`.
  - Add image sitemap tags for featured images.
  - Add lastmod timestamps based on `post_modified_gmt`.
