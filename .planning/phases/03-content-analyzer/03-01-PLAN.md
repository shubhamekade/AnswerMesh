# Plan 03-01: Content Parser & Semantic Structure Inspector

**Phase:** 3 — Content Analyzer & Entity Extraction  
**Plan ID:** 03-01  
**Type:** Tracer Slice  
**Requirements Addressed:** REQ-F11, NFR-02, NFR-03  
**Status:** Planned  

---

## 1. Objective
Build DOM content analyzer parsing post HTML to evaluate heading hierarchy (H1–H6), word count, paragraph length, image alt tags, internal and external link counts, and readability.

---

## 2. Context & Design Decisions
- **Parser Engine:** Use PHP `DOMDocument` / `libxml` with UTF-8 encoding handling, with regex fallbacks.
- **Audits Evaluated:**
  - H1 existence, uniqueness, and match with page topic.
  - Heading order skips (e.g. H2 followed directly by H4).
  - Word count thresholds (thin content warning if <300 words for articles).
  - Paragraph length (flag walls of text >120 words).
  - Image alt coverage (% of images with descriptive alt text).
  - Internal vs. external link ratio.

---

## 3. Detailed Tasks

### Task 1: Post Content Analyzer
- Create `includes/class-post-analyzer.php`:
  - Method `analyze_post(int $post_id): array`
  - Extraction:
    - Headings list with tag level, text, and order.
    - Word count and estimated read time.
    - Images list with `src`, `alt`, and missing alt count.
    - Links list separated into internal (matching site domain) vs external, with anchor text.
  - Structural validation:
    - `has_single_h1`: boolean.
    - `heading_skips`: list of skipped levels.
    - `thin_content`: boolean (<300 words).
    - `missing_alt_count`: integer.

---

## 4. Verification & Acceptance Criteria
- [ ] HTML with multiple H1s or skipped heading levels correctly flagged.
- [ ] Word count accurately measured on rendered content.
- [ ] Alt text missing counts identified accurately.
- [ ] `php -l` passes on `class-post-analyzer.php`.
