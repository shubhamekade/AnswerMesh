# Plan 03-02: Question Discovery & Business Knowledge Base

**Phase:** 3 — Content Analyzer & Entity Extraction  
**Plan ID:** 03-02  
**Type:** Core Feature Subsystem  
**Requirements Addressed:** REQ-F12, REQ-F13, NFR-01, NFR-02  
**Status:** Planned  

---

## 1. Objective
Build the Business Knowledge Base manager storing verified company facts into `wp_aiseo_entities` and implement question extraction detecting questions in headings/content, categorizing intent, and checking answer coverage in `wp_aiseo_questions`.

---

## 2. Context & Design Decisions
- **Business Knowledge Store:** Uses `wp_aiseo_entities` table for Organization, Person, Services, Products, and Locations. Provides REST API helper methods to retrieve verified business context.
- **Question Extraction Engine:**
  - Regex & linguistic patterns detecting question markers (Who, What, Where, When, Why, How, Is, Does, Can, Should) in headings (H2, H3, FAQ sections) and paragraph sentences ending in `?`.
  - Intent classification: `informational`, `commercial`, `transactional`, `comparison`, `local`.
  - Answer evaluation: Checks whether the succeeding block/paragraph directly answers the question within 50–100 words. Status: `answered`, `weak`, `missing`.

---

## 3. Detailed Tasks

### Task 1: Entity & Business Knowledge Manager
- Create `includes/class-entity.php`:
  - CRUD operations on `{$wpdb->prefix}aiseo_entities`.
  - Standard entity types: `organization`, `person`, `service`, `product`, `location`.
  - Method `get_verified_context(): array`: Returns structured string summary for AI prompts and analysis.

### Task 2: Question Discovery & Coverage Engine
- Create `includes/class-question-engine.php`:
  - Method `extract_questions_from_post(int $post_id, string $content): array`
  - Pattern matching for interrogative sentences in headings and body text.
  - Intent classifier based on keywords:
    - Comparison: "vs", "versus", "difference between", "compare".
    - Commercial/Transactional: "cost", "price", "hire", "buy", "provider", "quote".
    - Local: "near me", city names, "in [location]".
    - Informational: general "how", "what", "why".
  - Proximity answer verification: checks length and relevance of answer text immediately following the question.
  - Sync with `wp_aiseo_questions` table.

---

## 4. Verification & Acceptance Criteria
- [ ] Questions in H2/H3 or body detected with punctuation or interrogative prefixes.
- [ ] Intent classified correctly (e.g. "How much does X cost?" marked commercial/transactional).
- [ ] Entity manager creates, updates, and queries entities in `wp_aiseo_entities`.
- [ ] `php -l` passes on all files.
