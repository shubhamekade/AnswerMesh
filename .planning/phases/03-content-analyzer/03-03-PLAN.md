# Plan 03-03: Trust Signal Evaluator & Bounded Site Crawler

**Phase:** 3 — Content Analyzer & Entity Extraction  
**Plan ID:** 03-03  
**Type:** Integration & Infrastructure  
**Requirements Addressed:** REQ-F14, REQ-F15, NFR-02  
**Status:** Planned  

---

## 1. Objective
Build the trust and citation readiness evaluator inspecting author credentials, citations, statistics, evidence links, and publish/modified timestamps, alongside a bounded background site crawler executing capped audits (50/500/5000 pages).

---

## 2. Context & Design Decisions
- **Trust Evaluation:**
  - Author bio existence, author display name, author avatar.
  - Presence of dates: publish date, modified date, freshness score.
  - Outbound authoritative citations: external links pointing to reputable sources (.edu, .gov, wikipedia, industry authorities).
  - Unbacked statistical claims detection: presence of numbers/percentages with no nearby citation link.
  - Contact/About links: verifies presence of site-level trust signals.
- **Bounded Crawler Engine:**
  - Strict pagination limits (Free: 50, Pro: 500, Agency: 5,000).
  - Batching: crawls 10 posts per run via WP-Cron (`answermesh_crawl_batch`) or REST trigger.
  - Progress tracking stored in option `answermesh_crawl_progress` (`{status: 'running', total: 45, processed: 10}`).

---

## 3. Detailed Tasks

### Task 1: Trust & Citation Readiness Evaluator
- Create `includes/class-trust-analyzer.php`:
  - Method `evaluate_post(int $post_id): array`
  - Signals analyzed:
    - `author_has_bio`: bool
    - `author_has_url`: bool
    - `published_date`: string
    - `modified_date`: string
    - `days_since_modified`: int
    - `external_citation_count`: int
    - `statistical_claims_flagged`: array
    - `citation_readiness_score`: 0–100

### Task 2: Bounded Site Crawler
- Create `includes/class-site-analyzer.php`:
  - Method `start_crawl(int $limit = 50): bool`
  - Method `process_batch(int $batch_size = 10): array`
  - Method `get_crawl_status(): array`
  - WP-Cron hook `answermesh_crawl_batch` registration and execution.
