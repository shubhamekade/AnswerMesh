# Plan 04-01: Layer Scoring Calculators

**Phase:** 4 — Multi-Layer Diagnostic Scoring System  
**Plan ID:** 04-01  
**Type:** Tracer Slice  
**Requirements Addressed:** REQ-F16, NFR-02  
**Status:** Planned  

---

## 1. Objective
Implement deterministic scoring algorithms for the 5 core diagnostic layers plus content quality: SEO (20%), AEO (20%), GEO (20%), Entity (15%), Trust (15%), Content (10%).

---

## 2. Context & Design Decisions
- **Layer 1 — SEO Score (0–100):** Title tag present/optimal length, meta description, single H1, canonical URL, robots indexable, image alt text coverage, internal link present.
- **Layer 2 — AEO Score (0–100):** Target questions identified, answered questions vs missing questions ratio, direct concise answers present.
- **Layer 3 — GEO Score (0–100):** Schema.org graph present, entity mentions structured, citation readiness, factual structure without ambiguity.
- **Layer 4 — Entity Score (0–100):** Organization entity populated, logo set, social links set, author entity linked to person.
- **Layer 5 — Trust Score (0–100):** Author bio present, freshness (<180 days), authoritative outbound citations, low unbacked statistics.
- **Layer 6 — Content Score (0–100):** Word count > 500, readable paragraphs (<120 words), heading hierarchy without level skips.

---

## 3. Detailed Tasks

### Task 1: Layer Scoring Evaluators
- Create `includes/class-score.php`:
  - `calculate_seo_score(int $post_id, array $meta, array $analysis): int`
  - `calculate_aeo_score(array $questions): int`
  - `calculate_geo_score(int $post_id, array $trust, array $schema): int`
  - `calculate_entity_score(): int`
  - `calculate_trust_score(array $trust): int`
  - `calculate_content_score(array $analysis): int`

---

## 4. Verification & Acceptance Criteria
- [ ] Each layer calculation returns an integer bounded strictly between 0 and 100.
- [ ] Missing critical items (e.g. no title, no H1, missing author bio) predictably penalize individual scores.
- [ ] `php -l` passes on `class-score.php`.
