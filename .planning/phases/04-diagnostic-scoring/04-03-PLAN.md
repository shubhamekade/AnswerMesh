# Plan 04-03: Evidence Model Recommendation Generator

**Phase:** 4 — Multi-Layer Diagnostic Scoring System  
**Plan ID:** 04-03  
**Type:** Integration & Infrastructure  
**Requirements Addressed:** REQ-F17, NFR-01, NFR-02  
**Status:** Planned  

---

## 1. Objective
Build the Evidence Model recommendation engine translating diagnostic findings into prioritized, evidence-backed actions containing `Observation`, `Evidence`, `Impact`, `Recommendation`, `Priority`, `Confidence`, and `Acceptance Check`, persisting to `wp_aiseo_recommendations`.

---

## 2. Context & Design Decisions
- **Evidence Structure:**
  - `type`: category (e.g. `missing_h1`, `missing_schema`, `unanswered_questions`, `unbacked_stats`, `missing_author_bio`).
  - `priority`: `CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `INFO`.
  - `confidence`: `High`, `Medium`, `Low`.
  - `title`: short headline.
  - `description`: context explanation.
  - `evidence`: specific data/snippet observed.
  - `acceptance_check`: verifiable test condition.
- **Priority Sorter:**
  - Rank recommendations by priority weight (`CRITICAL` > `HIGH` > `MEDIUM` > `LOW` > `INFO`).
- **Sync:**
  - Clear previous pending recommendations for post/site and insert fresh actionable recommendations.

---

## 3. Detailed Tasks

### Task 1: Recommendation Engine
- Create `includes/class-recommendation-engine.php`:
  - `generate_recommendations(int $post_id, array $analysis, array $trust, array $questions, array $scores): array`
  - Rule checkers:
    - Missing title or meta description -> `HIGH`
    - Multiple H1s or heading level skips -> `MEDIUM`
    - Missing Organization entity -> `HIGH`
    - Target questions unanswered (>50% missing) -> `HIGH`
    - Unbacked statistics detected -> `MEDIUM`
    - Missing author bio -> `MEDIUM`
    - Thin content (<300 words) -> `HIGH`
  - Method `sync_recommendations(int $post_id, array $recommendations): void`
  - Method `get_top_priorities(int $limit = 5): array`
