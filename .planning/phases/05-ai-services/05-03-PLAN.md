# Plan 05-03: Prompt Builder, Content Assistant & Diff Generator

**Phase:** 5 — AI Intelligence Services & Provider Abstraction  
**Plan ID:** 05-03  
**Type:** Integration & Infrastructure  
**Requirements Addressed:** REQ-F20, REQ-F21, NFR-01, NFR-04  
**Status:** Planned  

---

## 1. Objective
Build the Prompt Builder injecting verified business knowledge and anti-hallucination guardrails, along with the Content Engine providing AI action generators (Generate Answer Block, Generate FAQ, Improve Content) and structured diff previews before applying.

---

## 2. Context & Design Decisions
- **Anti-Hallucination Guardrails:**
  - Explicit system instruction: "You are an AI search visibility assistant. Strictly use provided verified business facts. Never invent credentials, awards, reviews, or statistics. If information is missing, explicitly state it is missing."
- **Actions Provided:**
  - `generate_answer_block(int $post_id, string $question): array`
  - `generate_faq(int $post_id, int $count = 3): array`
  - `improve_content_section(int $post_id, string $section): array`
- **Diff / Proposal Architecture:**
  - Returns: `{ original: string, proposed: string, reason: string, confidence: string }`.
  - Preview before apply. Apply only commits upon explicit user confirmation via REST endpoint `POST /posts/{id}/apply-diff`.

---

## 3. Detailed Tasks

### Task 1: Prompt Builder
- Create `includes/class-prompt-builder.php`:
  - `build_answer_prompt(string $question, string $post_content, string $business_context, string $brand_voice): string`
  - `build_faq_prompt(string $post_title, string $post_content, string $business_context): string`
  - `build_improvement_prompt(string $content, string $instruction, string $business_context): string`

### Task 2: Content Engine & Proposal Manager
- Create `includes/class-content-engine.php`:
  - Executes prompts through active AI provider.
  - Generates before/after proposals with diff information.
  - Method `apply_proposal(int $post_id, string $type, string $content): bool`.
  - REST route binding in `class-rest-api.php`.

---

## 4. Verification & Acceptance Criteria
- [ ] Prompts contain verified business knowledge and anti-hallucination rules.
- [ ] Proposals structured as before/after diffs.
- [ ] No changes automatically overwrite post without user approval.
- [ ] `php -l` passes on all files.
