# Plan 06-01: React Admin Dashboard & Score Gauge

**Phase:** 6 — Admin Dashboard & Editor Experience  
**Plan ID:** 06-01  
**Type:** Tracer Slice  
**Requirements Addressed:** REQ-F23, NFR-02, NFR-03  
**Status:** Planned  

---

## 1. Objective
Build the React Admin Dashboard application shell with tabbed navigation (Dashboard, Knowledge Base, Pages, Settings), score gauge display showing the composite AnswerMesh Visibility Score, and 5 sub-layer progress bars.

---

## 2. Context & Design Decisions
- **Component Stack:** Uses `@wordpress/components` (`TabPanel`, `Card`, `Button`, `Spinner`, `Notice`) and `@wordpress/element`.
- **Score Visualization:**
  - Composite score radial/circular gauge or prominent numerical card with diagnostic rating badge (Needs Attention, Fair, Good, Excellent).
  - 5 Layer Breakdown meters:
    - SEO (20%)
    - AEO (20%)
    - GEO (20%)
    - Entity (15%)
    - Trust (15%)
    - Content (10%)
- **Data Source:** Consumes `/wp-json/aiseo/v1/dashboard` via `@wordpress/api-fetch`.

---

## 3. Detailed Tasks

### Task 1: Admin Tab Shell & Dashboard View
- Create `src/components/Navigation.js`: Tab panel controller switching between Dashboard, Knowledge Base, Page Analysis, and Settings.
- Create `src/components/ScoreGauge.js`: Render overall score (0–100) with color states (green >=70, amber 50-69, red <50) and progress bars for the 5 layers.
- Create `src/components/DashboardView.js`: Integrates score gauge, crawl triggers, and priority overview.

---

## 4. Verification & Acceptance Criteria
- [ ] Dashboard view renders site scores and 5 sub-layer bars from API.
- [ ] Tab switching navigates seamlessly without full page reloads.
- [ ] Loading and error states handled cleanly.
