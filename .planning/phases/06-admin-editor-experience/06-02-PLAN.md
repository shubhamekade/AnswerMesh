# Plan 06-02: Recommendations Feed, Knowledge Base UI & Settings

**Phase:** 6 — Admin Dashboard & Editor Experience  
**Plan ID:** 06-02  
**Type:** Feature Slice  
**Requirements Addressed:** REQ-F17, REQ-F23, REQ-F03, REQ-F05  
**Status:** Planned  

---

## 1. Objective
Implement the Recommendations Feed featuring the 7-attribute Evidence Model, the Business Knowledge Base manager for verified entity management, and the Settings / Setup Wizard interface.

---

## 2. Context & Design Decisions
- **Evidence Model Fidelity:** Each recommendation card clearly displays:
  - Observation
  - Evidence
  - Impact
  - Recommendation
  - Priority badge (Critical, High, Medium, Low)
  - Confidence (High, Medium, Low)
  - Acceptance Check
- **Knowledge Base UI:**
  - Entity types: Organization, Person, Service, Product, Location.
  - Dynamic field forms storing structured data payload in `wp_aiseo_entities`.
- **Settings & Setup Wizard:**
  - AI Provider settings: OpenAI & Google Gemini selection, encrypted API key inputs with masked display and test connection button.
  - Brand voice guidelines and SEO defaults.
  - Bounded crawler execution triggers (crawl post batches).

---

## 3. Detailed Tasks

### Task 1: Recommendations Feed Component
- Create `src/components/RecommendationsView.js`:
  - Fetch pending recommendations from `GET /wp-json/aiseo/v1/recommendations`.
  - Filter controls by priority (`CRITICAL`, `HIGH`, `MEDIUM`, `LOW`, `ALL`) and layer.
  - Expandable card detailing the full Evidence Model.
  - Apply action button to trigger automatic or guided resolution.

### Task 2: Business Knowledge Base Manager
- Create `src/components/KnowledgeBaseView.js`:
  - Fetch verified entities from `GET /wp-json/aiseo/v1/entities`.
  - Add / Edit / Delete modal for entities with JSON attribute editor or structured fields.
  - Visual badges indicating entity classification and relationship consistency.

### Task 3: Settings Panel & Setup Wizard
- Create `src/components/SettingsView.js`:
  - Tabs/Sections: AI Connection, Brand Voice, Crawl Settings, Privacy.
  - API Key input with test connection integration calling `POST /wp-json/aiseo/v1/ai/test-connection`.
  - First-time onboarding banner/modal for initial site configuration.

---

## 4. Verification & Acceptance Criteria
- [ ] Recommendations display all 7 Evidence Model attributes with functional priority filters.
- [ ] Knowledge Base allows creating, updating, and deleting entities via REST API.
- [ ] Settings view securely handles API keys and test connection provides instant feedback.
