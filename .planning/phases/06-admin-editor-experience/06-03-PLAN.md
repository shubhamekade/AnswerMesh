# Plan 06-03: Gutenberg Sidebar Plugin & Diff Approval Modal

**Phase:** 6 — Admin Dashboard & Editor Experience  
**Plan ID:** 06-03  
**Type:** Integration Slice  
**Requirements Addressed:** REQ-F21, REQ-F24, NFR-01, NFR-02  
**Status:** Planned  

---

## 1. Objective
Implement the Gutenberg Block Editor sidebar plugin (`answermesh-sidebar`) for live post diagnostic scoring, question coverage insights, AI assistance triggers, and the human-in-the-loop Diff Approval modal.

---

## 2. Context & Design Decisions
- **Gutenberg Integration:**
  - Uses `wp.plugins.registerPlugin` and `wp.editPost.PluginSidebar`.
  - Icon: Custom SVG or Dashicon `superhero` / `search`.
- **Sidebar Panels:**
  - **Live Score Panel:** Shows current post's overall AnswerMesh score and 5-layer progress breakdown (SEO, AEO, GEO, Entity, Trust). Includes "Re-Analyze Post" button.
  - **Question Discovery Panel:** Lists discovered questions for current post with coverage flags (`Answered`, `Weak`, `Missing`).
  - **AI Assistant Actions Panel:** One-click triggers for:
    - "Generate Direct Answer Block"
    - "Generate FAQ Section"
    - "Optimize Entity Clarity"
  - **Schema Inspector Panel:** Displays structured data preview for this post.
- **Diff Preview & Approval Modal:**
  - Human-in-the-loop safety requirement (REQ-F21): No AI output commits directly without review.
  - Visual side-by-side or stacked diff modal showing original content vs. proposed content.
  - Action buttons: "Approve & Insert into Post", "Copy to Clipboard", "Cancel / Discard".
  - Insertion automatically injects Gutenberg blocks or updates post content, followed by auto-re-scoring.

---

## 3. Detailed Tasks

### Task 1: Gutenberg Sidebar Registration & State Management
- Create `src/gutenberg/index.js` & `src/gutenberg/sidebar.js`:
  - Register Gutenberg sidebar plugin.
  - Connect to `@wordpress/data` (core/editor store) to read post ID, content, and title.
  - Fetch post diagnostic data from `GET /wp-json/aiseo/v1/posts/{id}/analysis`.

### Task 2: Question Engine & AI Triggers
- Create `src/gutenberg/QuestionPanel.js` & `src/gutenberg/AiActionsPanel.js`:
  - Render questions with status chips.
  - Action handlers dispatching requests to `/wp-json/aiseo/v1/posts/{id}/generate-answer` and `/generate-faq`.
  - Handle loading spinners and error notices gracefully.

### Task 3: Interactive Diff Approval Modal
- Create `src/gutenberg/DiffModal.js`:
  - Modal component with original content, proposed changes, and explanation.
  - Block insertion logic using `wp.data.dispatch('core/block-editor').insertBlocks`.
  - Immediate post score refresh trigger upon block insertion.

### Task 4: Asset Enqueue Hook
- Update `admin/class-admin-menu.php` (or add asset enqueue in `includes/class-plugin.php`):
  - Hook into `enqueue_block_editor_assets` to load `build/gutenberg.js` and `build/gutenberg.css` (or unified bundle) with localized settings, nonce, and REST URL.

---

## 4. Verification & Acceptance Criteria
- [ ] AnswerMesh sidebar icon appears in Gutenberg post edit screens.
- [ ] Live post scores and question coverage are rendered accurately.
- [ ] AI actions generate proposals that appear in Diff Approval modal.
- [ ] Content is only inserted into the editor when user explicitly clicks "Approve".
- [ ] Zero frontend script contamination on non-admin/editor pages.
