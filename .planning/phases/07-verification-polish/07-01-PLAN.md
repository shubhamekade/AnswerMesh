# Plan 07-01: Automated Test Suites & Test Harness

**Phase:** 7 — Verification, Security Hardening & MVP Polish  
**Plan ID:** 07-01  
**Type:** Test Slice  
**Requirements Addressed:** NFR-05, REQ-F16, REQ-F17, REQ-F07  
**Status:** Planned  

---

## 1. Objective
Establish an automated test harness covering critical subsystems: cryptographic key security, Schema.org JSON-LD graph generation, multi-layer diagnostic scoring equations, and Evidence Model recommendation validation.

---

## 2. Context & Design Decisions
- **Test Architecture:** Standalone PHP test suite runner that executes under CLI without requiring a running MySQL server, providing complete WordPress mocks for options, transients, post meta, and filters.
- **Coverage Domains:**
  - Encryption & Masking (`Encryption::encrypt`, `Encryption::decrypt`, `Encryption::mask_key`).
  - Schema Graph Output (`Schema::get_unified_graph`, Organization, Article, FAQ, Breadcrumbs).
  - Diagnostic Scoring Engine (`Score::calculate_composite_score`, layer weights, rating boundaries).
  - Recommendation Engine (`RecommendationEngine::create_recommendation`, 7 Evidence Model attributes).
  - AI Safe Prompting & Providers (`PromptBuilder::build_contextual_prompt`, anti-hallucination constraints).

---

## 3. Detailed Tasks

### Task 1: Lightweight Test Runner & WordPress Mock Harness
- Create `tests/bootstrap.php`: Provides WordPress constants (`ABSPATH`, `ARRAY_A`, etc.), stub functions (`get_option`, `update_option`, `get_post_meta`, `wp_create_nonce`, `__`, `esc_html`, etc.), and mock `$wpdb`.
- Create `tests/runner.php`: Discovers and executes all test cases with assertion counts and green/red terminal reporting.

### Task 2: Subsystem Test Cases
- Create `tests/test-encryption.php`: Test roundtrip encryption/decryption, wrong key rejection, masking.
- Create `tests/test-schema.php`: Validate `@graph` JSON-LD structure, ISO-8601 timestamps, conflict detection.
- Create `tests/test-scoring.php`: Test exact percentage weights (SEO 20%, AEO 20%, GEO 20%, Entity 15%, Trust 15%, Content 10%) and rating classification.
- Create `tests/test-evidence-model.php`: Validate that all 7 required attributes are populated with valid types.

---

## 4. Verification & Acceptance Criteria
- [ ] Test runner executes via `php tests/runner.php` with 100% passing assertions.
- [ ] All 5 target subsystems covered by automated assertions.
