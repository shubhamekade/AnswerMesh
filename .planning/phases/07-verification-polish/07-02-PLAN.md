# Plan 07-02: Security Audit & Performance Benchmarking

**Phase:** 7 — Verification, Security Hardening & MVP Polish  
**Plan ID:** 07-02  
**Type:** Security & Quality Slice  
**Requirements Addressed:** NFR-01, NFR-02, NFR-03, NFR-04  
**Status:** Planned  

---

## 1. Objective
Perform a comprehensive security audit of all PHP database queries, REST API endpoints, capability gates, and nonces. Benchmark public frontend execution overhead to verify it stays well below the 50ms requirement with zero outbound HTTP/AI requests.

---

## 2. Context & Design Decisions
- **Security Checkpoints:**
  - SQL Injection: All direct queries must use `$wpdb->prepare()` with proper specifiers (`%d`, `%s`).
  - XSS & Output Sanitization: All output tags escaped (`esc_attr`, `esc_html`, `esc_url`).
  - Access Control: REST routes verify `current_user_can('manage_options')` or `current_user_can('edit_posts')`.
  - Secret Protection: API keys never exposed in localized scripts or DOM data attributes.
  - Nonces: Verified on REST calls via `X-WP-Nonce`.
- **Performance Profiling:**
  - Automated benchmark measuring frontend head injection execution time across 1,000 iterations.
  - Verify zero `wp_remote_*` calls on frontend page loads.

---

## 3. Detailed Tasks

### Task 1: Static Security Code Audit Script
- Create `tests/audit-security.php`:
  - Scans all `.php` files for unescaped `$wpdb->query` interpolations.
  - Checks permission callbacks on all registered REST routes.
  - Verifies key masking logic and ensures API keys are omitted from `wp_localize_script`.

### Task 2: Frontend Performance Benchmark Script
- Create `tests/benchmark-performance.php`:
  - Instantiates `MetaOutput` and `SchemaOutput`.
  - Runs microsecond timing loop (1,000 cycles) to measure average overhead.
  - Confirms average execution is strictly < 50ms (target < 5ms).
  - Confirms zero outbound network requests.

---

## 4. Verification & Acceptance Criteria
- [ ] Security audit passes with zero critical SQLi, XSS, or capability bypass findings.
- [ ] Performance benchmark verifies frontend overhead is under 50ms.
