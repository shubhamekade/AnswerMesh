## 1. Objective
Establish the database architecture and REST API controller for Topic Clusters in AnswerMesh. Create the `wp_aiseo_clusters` table via database migration, build the `Cluster` data model manager, and expose complete REST endpoints for cluster retrieval, creation, updating, deletion, and post assignment.

---

## 2. Context & Design Decisions
- **Database Architecture:**
  - Table name: `{$wpdb->prefix}aiseo_clusters`.
  - Schema captures: `id`, `name`, `slug`, `pillar_post_id`, `posts_json`, `entities_json`, `coverage_score`, `subtopics_json`, `created_at`, `updated_at`.
  - Indexes on `slug` and `pillar_post_id` for fast query lookup.
- **Data Model (`includes/class-cluster.php`):**
  - Encapsulates database queries with prepared statements.
  - Handles JSON serialization/deserialization for `posts_json`, `entities_json`, and `subtopics_json`.
  - Provides helper methods: `get_all()`, `get_by_id()`, `create()`, `update()`, `delete()`, `get_by_post_id()`, `assign_post()`, `remove_post()`.
- **REST API Routes (`/wp-json/aiseo/v1/clusters`):**
  - `GET /clusters`: List all clusters with member count, pillar title, and coverage scores.
  - `GET /clusters/{id}`: Detailed view of a single cluster including post metadata and subtopic gaps.
  - `POST /clusters`: Create a new topic cluster (enforces `manage_options` capability).
  - `PUT /clusters/{id}`: Update an existing topic cluster or modify assigned posts.
  - `DELETE /clusters/{id}`: Delete a topic cluster without deleting associated WordPress posts.
  - `POST /clusters/sync`: Trigger cluster sync or automated analysis.

## 3. Detailed Tasks

### Task 1: Update Database Migration in `includes/class-database.php`
- Add table `wp_aiseo_clusters` to `create_tables()` schema definition.
- Increment `DB_VERSION` from `1.0.0` to `1.1.0`.
- Update `drop_tables()` in `Database` and `uninstall.php` to clean up `wp_aiseo_clusters` on purge.

### Task 2: Create `includes/class-cluster.php`
- Implement class `AnswerMesh\Cluster` with strict types and sanitization.
- Methods:
  - `static get_all(): array`
  - `static get(int $id): ?array`
  - `static create(array $data): int`
  - `static update(int $id, array $data): bool`
  - `static delete(int $id): bool`
  - `static get_cluster_for_post(int $post_id): ?array`
  - `static assign_posts(int $cluster_id, array $post_ids): bool`
  - `static calculate_cluster_score(int $cluster_id): int`

### Task 3: Expose REST API Endpoints in `includes/class-rest-api.php`
- Register the `/clusters` route group under `aiseo/v1`.
- Add permission callback verifying `manage_options` or `edit_posts` as appropriate.
- Implement controller methods:
  - `get_clusters(WP_REST_Request $request): WP_REST_Response`
  - `get_cluster(WP_REST_Request $request): WP_REST_Response`
  - `create_cluster(WP_REST_Request $request): WP_REST_Response`
  - `update_cluster(WP_REST_Request $request): WP_REST_Response`
  - `delete_cluster(WP_REST_Request $request): WP_REST_Response`
  - `sync_clusters(WP_REST_Request $request): WP_REST_Response`

### Task 4: Add Automated Unit Tests
- Create `tests/test-cluster.php` testing table creation, CRUD operations, and post assignment.
- Register suite in `tests/runner.php`.
