## 1. Objective
Build the intelligent backend engine `ClusterEngine` (`includes/class-cluster-engine.php`) to automatically discover topic clusters, nominate pillar pages based on semantic completeness and hierarchy, detect topical subtopic gaps across cluster members, and classify orphan posts lacking cluster affiliation.

---

## 2. Context & Design Decisions
- **Automated Cluster Discovery Heuristics:**
  - Aggregates published posts and evaluates semantic relationships using:
    - Primary categories and tags.
    - Verified entity co-occurrences (from `wp_aiseo_entities`).
    - Semantic heading keywords and extracted question topics (from `wp_aiseo_questions`).
  - Clusters posts that share high topical overlap.
- **Pillar Nomination Algorithm:**
  - Evaluates candidate posts within a cluster using a composite Pillar Index:
    - Word count & comprehensive depth (30%).
    - Highest diagnostic overall score (25%).
    - Number of verified entities referenced (25%).
    - Internal heading breadth (20%).
  - Post with the highest Pillar Index is nominated as the cluster pillar; remaining posts become supporting cluster items.
- **Topical Subtopic Gap Analysis:**
  - Compares questions and entities covered in individual cluster posts against the aggregate cluster footprint.
  - Flags missing subtopics: If Post A and Post B cover a subtopic or entity relevant to the cluster pillar, but the pillar or other cluster posts lack coverage, a subtopic gap is registered.
- **Orphan Post Classification:**
  - Identifies published posts that:
    1. Are not associated with any active topic cluster (`cluster_orphan`).
    2. Have low semantic overlap (<20%) with all known clusters.
- **Evidence Model Integration:**
  - Connects to `RecommendationEngine` to emit structured findings:
    - `CRITICAL`: Orphan pillar content without supporting cluster articles.
    - `HIGH`: Unassigned orphan posts with significant organic potential.
    - `MEDIUM`: Subtopic gaps in established topic clusters.

## 3. Detailed Tasks

### Task 1: Create `includes/class-cluster-engine.php`
- Implement class `AnswerMesh\ClusterEngine`:
  - `discover_clusters(): array` — analyzes all published posts and suggests new clusters or cluster expansions.
  - `evaluate_pillar_candidate(array $post_ids): int` — selects the best pillar page among a group of related posts.
  - `analyze_subtopic_gaps(int $cluster_id): array` — detects missing entities, unanswered questions, and coverage deficits within a cluster.
  - `get_orphan_posts(): array` — returns all published posts not currently assigned to any cluster.
  - `calculate_cluster_health(int $cluster_id): array` — calculates coverage score (0–100), completeness rating, and gap summary.

### Task 2: Integrate with `RecommendationEngine` in `includes/class-recommendation-engine.php`
- Add cluster-aware recommendations:
  - `cluster_orphan_post`: Suggests assigning isolated post to an existing cluster or establishing it as a new pillar.
  - `cluster_subtopic_gap`: Recommends adding missing subtopics or FAQ pairs to the cluster pillar.
  - `cluster_weak_pillar`: Recommends expanding the pillar post when supporting posts exceed it in depth.

### Task 3: Expose Engine Methods in REST API
- Update `includes/class-rest-api.php`:
  - `GET /aiseo/v1/clusters/orphans`: Returns list of orphan posts with suggested clusters.
  - `GET /aiseo/v1/clusters/{id}/gaps`: Returns detected subtopic gaps for a specific cluster.
  - `POST /aiseo/v1/clusters/auto-discover`: Executes clustering discovery and returns suggested groupings.

### Task 4: Add Automated Unit Tests
- Create `tests/test-cluster-engine.php` testing pillar nomination logic, subtopic gap discovery, and orphan classification.
- Register suite in `tests/runner.php`.
