# Plan 08-03: React Cluster Explorer & Admin Management UI

**Phase:** 8 — Topic Clusters & Semantic Depth Engine  
**Plan ID:** 08-03  
**Type:** UI / Frontend Slice  
**Requirements Addressed:** REQ-M2-04  
**Status:** Planned  

---

## 1. Objective
Create the React-powered **Topic Clusters** explorer view in the AnswerMesh Admin Dashboard. Provide visual cluster hierarchy cards, pillar-to-cluster post mappings, topical depth gauges, an orphan posts resolution drawer, and interactive cluster editing tools using `@wordpress/components`.

---

## 2. Context & Design Decisions
- **UI Architecture:**
  - Build new component `src/components/ClustersView.js`.
  - Add navigation tab in `src/components/Navigation.js`: "Topic Clusters" with badge showing active cluster count.
  - Follow the unified aesthetic established in Milestone 1: CSS custom properties, cards, clean typography, responsive layout, smooth state transitions.
- **Key View Components:**
  1. **Cluster Metrics Header:** Total Clusters, Clustered Posts %, Orphan Posts count, Average Topical Depth Score.
  2. **Cluster Cards Grid:**
     - Pillar post headline with link to edit.
     - Supporting cluster posts list with badges.
     - Topical completeness circular gauge or progress bar (0–100%).
     - Subtopic gap callouts (e.g., "3 missing subtopics detected").
     - Quick actions: "Add Supporting Post", "Edit Cluster", "Delete".
  3. **Auto-Discovery Action Bar:**
     - "Run Auto-Discovery" button: Triggers `/aiseo/v1/clusters/auto-discover` and presents proposed clusters in a preview drawer.
     - "Create Cluster" button: Opens modal to manually name cluster, designate pillar, and select supporting posts.
  4. **Orphan Posts Drawer / Resolution Panel:**
     - Collapsible section showing posts without a cluster.
     - Quick "Assign to Cluster" dropdown for each orphan post.
- **Build & Bundle:**
  - Build with `@wordpress/scripts` (`npm run build`).
  - Output verified in `build/index.js` and `build/index.css`.

---

## 3. Detailed Tasks

### Task 1: Create `src/components/ClustersView.js`
- Implement stateful React component fetching from `/aiseo/v1/clusters` and `/aiseo/v1/clusters/orphans`.
- State management for:
  - `clusters`: Array of active clusters with member details.
  - `orphans`: Array of unassigned posts.
  - `selectedCluster`: Cluster currently being edited or viewed.
  - `isCreateModalOpen`: Toggle for manual cluster creation modal.
  - `isDiscovering`: Loading state for auto-discovery background run.
- Render metrics overview cards at the top.
- Render cluster grid with pillar-and-support visual structure.
- Render modal dialogs for cluster creation, editing, and orphan assignment.

### Task 2: Integrate Tab in `src/components/Navigation.js` and App Shell
- Update `Navigation.js` to add `clusters` tab with appropriate dashicon (`category` or `networking`).
- Update `DashboardView.js` or main tab switcher to render `ClustersView` when active tab is `clusters`.

### Task 3: Add Cluster UI Styles in `src/index.css`
- Add styles for:
  - `.answermesh-cluster-card`: Card layout, pillar badge, member list styling.
  - `.answermesh-pillar-header`: Distinct visual emphasis for the pillar post.
  - `.answermesh-orphan-drawer`: Clean expandable drawer for unassigned content.
  - `.answermesh-cluster-gauge`: Compact circular or linear depth meter.

### Task 4: Recompile Production Assets & Test
- Run build process to produce updated `build/index.js` and `build/index.css`.
- Verify asset loading without JavaScript console errors in WordPress admin context.
