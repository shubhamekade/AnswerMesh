# Plan 09-03: Gutenberg 1-Click Link Assistant & Admin Decay/Link Hub

**Phase:** 9 — Content Freshness & Sitewide Internal Link Graph  
**Plan ID:** 09-03  
**Type:** UI / Full-Stack Slice  
**Requirements Addressed:** REQ-M2-09, REQ-M2-10  
**Status:** Planned  

---

## 1. Objective
Create the human-in-the-loop Gutenberg block editor sidebar link assistant and the React Admin "Links & Freshness" Hub view. Provide editors with 1-click contextual internal link insertion and provide administrators with a centralized dashboard for content decay queues and link equity distribution.

---

## 2. Context & Design Decisions
- **Gutenberg Editor Integration (`src/gutenberg/sidebar.js`):**
  - Add "Internal Link Opportunities" accordion panel in the AnswerMesh editor sidebar.
  - Fetches `/aiseo/v1/links/opportunities?post_id={currentPostId}`.
  - Displays suggested target post, anchor keyword, and contextual sentence snippet.
  - Action buttons:
    - "Insert Link": Searches blocks in editor for target phrase and wraps in hyperlink `<a href="...">anchor</a>` via block editor dispatch.
    - "Copy Link": Copies markdown link or HTML link to clipboard.
  - Strictly requires human approval click before any block change is dispatched.
- **React Admin Hub (`src/components/LinkDecayView.js`):**
  - Navigation tab: "Links & Freshness" in `src/components/Navigation.js`.
  - Metrics banner: Total Internal Links, True Orphan Pages count, Decaying Posts count, Average Link Equity.
  - Tab panels or split view:
    - **Freshness & Decay Queue:** Filterable by status tier (`Critical`, `Decaying`, `Aging`, `Fresh`), showing post title, last modified date, days ago, and "Edit" link.
    - **Internal Link Equity Table:** Showing posts with in-degree, out-degree, orphan warning, and top suggested internal targets.
  - Clean CSS styles in `src/index.css`.
  - Build bundle updated via `@wordpress/scripts`.
