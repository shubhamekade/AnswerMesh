# Plan 10-02: Scheduled Sampling Runner, Citation Parser & Competitor Tracker

**Phase:** 10 — Observed AI Search Visibility Engine  
**Plan ID:** 10-02  
**Type:** Background Engine Slice  
**Requirements Addressed:** REQ-M3-02, REQ-M3-03, REQ-M3-04, REQ-M3-05, NFR-M3-01, NFR-M3-02

---

## 1. Objective
Build `AnswerMesh\VisibilityRunner` (`includes/class-visibility-runner.php`) to execute automated query sampling across generative search engines (ChatGPT, Gemini, Perplexity, Copilot). Support WP-Cron scheduling, on-demand REST execution, text parsing for source citations & branded mentions, extraction of rival competitor domains, and computation of an aggregate AI Visibility Index (0–100).

---

## 2. Context & Design Decisions
- **Query Source & Prioritization:**
  - Extracts target queries from high-priority questions in `wp_aiseo_questions`, pillar post titles, and focus topics in postmeta (`_aiseo_focus_topic`).
- **Engines & Providers:**
  - Supported platforms: `chatgpt`, `gemini`, `perplexity`, `copilot`.
  - Rate limiting & budget protection (NFR-M3-01): Maximum 5 queries sampled per cron tick; daily quota check stored in transient/option.
  - Offline simulation (NFR-M3-02): When live API keys or external search APIs are absent, generate deterministic benchmark observations based on entity coverage, schema quality, and domain authority.
- **Citation & Competitor Extraction (REQ-M3-03, REQ-M3-04):**
  - Citation detection: Searches response text for site domain, canonical post URLs, or markdown citations `[1]`, `(source: ...)`.
  - Brand mention: Scans response text for site business name / Organization entity.
  - Competitor discovery: Regular expression extraction of foreign `http(s)://` domains and capitalization patterns denoting competing commercial brands in the same response.
- **AI Visibility Index (REQ-M3-05):**
  - Composite formula (0–100):
    - Platform Presence (Observed in query): 35%
    - Direct Citation Rate: 35%
    - Brand Mention Prominence: 20%
    - Competitor Gap Factor: 10%
- **Evidence Model Integration:**
  - Emits `ai_visibility_gap` recommendations for tracked queries where competitors were cited but site was not observed.
- **REST Endpoints (`includes/class-rest-api.php`):**
  - `POST /aiseo/v1/visibility/run-sample`: Triggers sampling batch on-demand for specific query or top queries.
  - `GET /aiseo/v1/visibility/competitors`: Aggregated list of top observed competitors and their citation share.

## 3. Detailed Tasks

   - `run_scheduled_sample(int $batch_size = 5): array`
   - `sample_query(string $query, string $platform = 'all'): array`
   - `parse_response(string $text, string $query, string $platform): array`
   - `calculate_visibility_index(int $days = 30): array`
   - `get_top_competitors(int $limit = 10): array`
2. Connect `ai_visibility_gap` in `includes/class-recommendation-engine.php`.
3. Register `/visibility/run-sample` and `/visibility/competitors` in `includes/class-rest-api.php`.
4. Register WP-Cron hook `aiseo_daily_visibility_check` in `includes/class-plugin.php`.
5. Add unit tests for runner, response parsing, and index calculation in `tests/test-visibility.php`.
