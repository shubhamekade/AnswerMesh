# Plan 10-03: React Admin Visibility Dashboard & Export Hub

**Phase:** 10 — Observed AI Search Visibility Engine  
**Plan ID:** 10-03  
**Type:** UI / Full-Stack Slice  
**Requirements Addressed:** REQ-M3-06  
**Status:** Planned  

---

## 1. Objective
Build the "AI Visibility" tab in the React Admin dashboard (`src/components/VisibilityView.js`) and register it in `src/components/Navigation.js`. Provide site administrators with an interactive dashboard displaying the composite AI Visibility Index, platform-by-platform presence cards (ChatGPT, Gemini, Perplexity, Copilot), top observed competitor share of voice, historical query observation logs, on-demand query test sampler, and 1-click CSV export.

---

## 2. Context & Design Decisions
- **UI Structure (`src/components/VisibilityView.js`):**
  - **Metrics Header Banner:**
    - AI Visibility Index radial/progress meter (0–100).
    - Total Queries Sampled.
    - Citation Rate %.
    - Top Competitor Share %.
  - **Platform Comparison Grid:**
    - 4 engine cards: ChatGPT, Gemini, Perplexity, Copilot with citation rate, mention count, and last observed timestamp.
  - **On-Demand Sampler Widget:**
    - Input box to enter a query and button "Run Observation".
    - Shows live result with observed badge, citation link, and competitor breakdown.
  - **Competitors & Share of Voice Panel:**
    - Table/list of discovered competitor domains with mention frequencies.
  - **Query Observation History Table:**
    - Searchable and platform-filterable table of historical checks.
    - Columns: Date, Query, Platform, Status (Cited / Mentioned / Absent), Source URL, Competitors.
  - **Export Action:**
    - "Export CSV" button generating instant downloadable CSV file of all query observation logs directly in-browser.
- **Styling (`src/index.css`):**
  - Add styles for visibility cards, engine badges, observation status tags, and export button.
- **Production Bundle:**
  - Build and compile updated `build/index.js` and `build/index.css` with `@wordpress/scripts`.
