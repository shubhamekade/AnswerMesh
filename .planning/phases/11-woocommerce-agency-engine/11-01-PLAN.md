# Plan 11-01: WooCommerce Schema & Product Question Extraction Engine

**Phase:** 11 — WooCommerce Structured Commerce & Agency Engine  
**Plan ID:** 11-01  
**Type:** Backend Commerce Engine Slice  
**Requirements Addressed:** REQ-M4-01, REQ-M4-02, NFR-M4-01, NFR-M4-02, NFR-M4-03  
**Status:** Planned  

---

## 1. Objective
Build `WooCommerceSchema` (`includes/class-woocommerce-schema.php`) and `ProductQuestionEngine` (`includes/class-product-question-engine.php`) to provide rich Schema.org e-commerce structured data (`Product`, `Offer`, `MerchantReturnPolicy`, `ShippingDetails`, `AggregateRating`) and extract product attributes into direct question-and-answer pairs for generative AI commerce engines, ensuring zero performance impact on cart/checkout pages and graceful deactivation when WooCommerce is inactive.

---

## 2. Context & Design Decisions
- **Zero Checkout / Cart Impact (NFR-M4-01):**
  - Check `is_checkout()`, `is_cart()`, `wp_doing_ajax()`, or WooCommerce webhook queries before executing schema or Q&A logic.
- **Graceful WooCommerce Detection (NFR-M4-02):**
  - Verify `class_exists('WooCommerce')` or `function_exists('wc_get_product')`. If absent, return empty arrays without throwing errors.
- **Product Schema (`REQ-M4-01`):**
  - Generates Schema.org `Product` JSON-LD including:
    - `@type`: `Product`
    - `name`, `description`, `image`, `sku`, `gtin`
    - `offers`: `Offer` with `price`, `priceCurrency`, `availability` (`https://schema.org/InStock` / `OutOfStock`), `seller`
    - `hasMerchantReturnPolicy`: 30-day standard or customizable return policy
    - `shippingDetails`: Free or flat-rate shipping specifications
    - `aggregateRating`: Rating score and review count if reviews exist
- **Product Question Answering (`REQ-M4-02`):**
  - Inspects product attributes (weight, dimensions, material, color, warranty, care instructions) and synthesizes high-intent Q&A (e.g., "What are the dimensions of X?", "What is the return policy?", "Is X in stock?").
  - Formats Q&A as Schema.org `FAQPage` or embedded `mainEntity` for generative search engines.
- **REST API Endpoints:**
  - `GET /aiseo/v1/commerce/product/(?P<id>\d+)/schema`
  - `GET /aiseo/v1/commerce/product/(?P<id>\d+)/qa`
