# Plan 11-02: Autonomous Buying Guide & Comparison Generator

**Phase:** 11 — WooCommerce Structured Commerce & Agency Engine  
**Plan ID:** 11-02  
**Type:** Autonomous Content & Commerce Engine Slice  
**Requirements Addressed:** REQ-M4-03, NFR-M4-01, NFR-M4-02, NFR-M4-03  
**Status:** Planned  

---

## 1. Objective
Build `BuyingGuideEngine` (`includes/class-buying-guide-engine.php`) to automatically generate category comparison matrices and buying guide content blocks for WooCommerce product categories. It extracts key attributes across category products, compares pricing, ratings, specifications, and synthesizes structured HTML tables and JSON data consumable via shortcode `[answermesh_buying_guide]`, Gutenberg block, or REST API.

---

## 2. Context & Design Decisions
- **Category Matrix Compilation:**
  - Queries published products belonging to a given product category taxonomy (`product_cat`).
  - Collects attributes, prices, ratings, and best-for labels (e.g. "Best Value", "Top Rated", "Premium Choice").
- **Structured Output:**
  - Structured comparison table with responsive HTML markup and clean CSS classes.
  - Generates summary recommendations highlighting pros/cons or suitability for different buyer intents.
  - JSON format for headless / REST consumers.
- **Shortcode & Gutenberg Integration:**
  - `[answermesh_buying_guide category="slug" limit="5" title="Buying Guide"]`
  - Zero checkout impact: skips execution if called in checkout/cart.
- **REST Endpoints:**
  - `GET /aiseo/v1/commerce/buying-guide?category_id=12`
  - `GET /aiseo/v1/commerce/categories`

---

## 3. Detailed Tasks
1. Implement `AnswerMesh\BuyingGuideEngine` in `includes/class-buying-guide-engine.php`.
2. Register shortcode `[answermesh_buying_guide]` and hook in plugin init.
3. Register `/commerce/buying-guide` and `/commerce/categories` in `includes/class-rest-api.php`.
4. Add unit test assertions in `tests/test-buying-guide.php` and register with `tests/runner.php`.

---

## 4. Verification & Acceptance Criteria
- [ ] Extracts products within category and compiles accurate comparison matrix.
- [ ] Generates valid comparison HTML table with proper styling hooks.
- [ ] Shortcode renders gracefully and handles non-existent or empty categories.
- [ ] Safe execution with zero interference with cart/checkout.
