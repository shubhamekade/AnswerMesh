# Plan 11-03: Multi-Site Management & Agency White-Label Hub

**Phase:** 11 — WooCommerce Structured Commerce & Agency Engine  
**Plan ID:** 11-03  
**Type:** Multisite & Agency Architecture Slice  
**Requirements Addressed:** REQ-M4-04, REQ-M4-05, REQ-M4-06, NFR-M4-03  
**Status:** Planned  

---

## 1. Objective
Build `MultiSiteManager` (`includes/class-multisite.php`), `WhiteLabel` (`includes/class-white-label.php`), and `AgencyReport` (`includes/class-agency-report.php`) to empower agencies with multi-site network settings inheritance, complete white-label rebranding of AnswerMesh in WordPress admin (custom plugin name, icon, support URL, removal of promotional credits), and 1-click comprehensive client audit reports summarizing SEO, AEO, GEO scores, topic clusters, and AI search visibility observations.

---

## 2. Context & Design Decisions
- **Multi-Site Management (`REQ-M4-04`):**
  - Detects `is_multisite()`.
  - Supports network-wide options (`get_site_option('answermesh_network_settings')`).
  - Allows child sites to inherit global network policies or enable per-site overrides if permitted by super admins.
- **Agency White-Label Branding (`REQ-M4-05`):**
  - Settings: `custom_plugin_name`, `custom_logo_url`, `custom_support_url`, `hide_branding_credits`.
  - Filters admin menu titles, page headers, schema author credits, and comment banners to display the agency's brand instead of AnswerMesh.
- **Agency Client Report Generator (`REQ-M4-06`):**
  - Compiles full site health summary:
    - Overall SEO, AEO, and GEO Scores with grades
    - Schema graph coverage status
    - Topic cluster distribution and orphan pages
    - Content decay stats
    - Observed AI search citations and competitor share of voice
  - Formats report as clean printable HTML and structured JSON exportable via REST API or direct download.
- **REST API Endpoints:**
  - `GET /aiseo/v1/agency/white-label`
  - `POST /aiseo/v1/agency/white-label`
  - `GET /aiseo/v1/agency/report`
  - `GET /aiseo/v1/agency/multisite-status`
