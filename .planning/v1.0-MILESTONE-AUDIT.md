## 3. Cross-Phase Integration Verification

1. **Database & Storage (Phase 1 ➔ Phases 2, 3, 4):**
   - Tables provisioned with proper indexes on `post_id` and `status`.
   - Score updates from Phase 4 persist seamlessly to `wp_aiseo_scores`.
   - Questions extracted in Phase 3 synchronize to `wp_aiseo_questions`.
2. **Schema & Metadata Pipeline (Phase 2 ➔ Phase 6 & Frontend):**
   - Public frontend renders valid JSON-LD graph cached via transients.
   - Gutenberg sidebar previews live schema without database thrashing.
3. **Analysis & Scoring Pipeline (Phase 3 ➔ Phase 4 ➔ Phase 6):**
   - `PostAnalyzer` feeds raw DOM metrics into `Score::calculate_overall()`.
   - `RecommendationEngine` generates typed findings matching the Evidence Model contract.
   - React Admin dashboard visualizes composite scores and layer breakdowns.
4. **AI Assistant & Safety Loop (Phase 5 ➔ Phase 6):**
   - AI prompts strictly inject verified entities from `KnowledgeBase`.
   - Generated suggestions return unified JSON diff payloads to `DiffModal.js`.
   - User approval commits blocks directly via `wp.data.dispatch('core/block-editor')`.
